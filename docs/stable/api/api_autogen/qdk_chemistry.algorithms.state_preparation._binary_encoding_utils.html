Bases: CaseInsensitiveStrEnum

Supported operation types for matrix compression.

Each member carries the integer discriminator consumed by BinaryEncoding.qs. Q# cannot compare strings in QIR-emitting code, so the wire value has to be an Int; declaring it alongside the name keeps the two from drifting.
